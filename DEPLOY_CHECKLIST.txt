PHASE 2: BACKEND (Railway)
---------------------------
[ ] 1. Sign up at https://railway.app/ with GitHub
[ ] 2. Click "New Project" → "Deploy from GitHub repo"
[ ] 3. Select your repository
[ ] 4. Set root directory: backend
[ ] 5. Add environment variables:
        - NODE_ENV=production
        - PORT=3000
        - DB_HOST=<your-tidb-host>
        - DB_USER=<your-tidb-user>
        - DB_PASSWORD=<your-tidb-password>
        - DB_NAME=paddy_management
        - DB_PORT=4000
        - JWT_SECRET=<generate-strong-secret>
        - FRONTEND_URL=https://your-app.vercel.app
[ ] 6. Deploy and copy backend URL

================================================================================
                         TROUBLESHOOTING
================================================================================

ISSUE: 404 errors on frontend
FIX: Ensure vercel.json has rewrites configured

ISSUE: CORS errors
FIX: Check FRONTEND_URL in backend matches Vercel URL exactly

ISSUE: Database connection fails
FIX: Verify TiDB credentials and SSL settings

ISSUE: Build fails
FIX: Check package.json scripts and dependencies

================================================================================
                         USEFUL COMMANDS
